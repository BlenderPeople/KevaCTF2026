# Hidden stream (Hard Edition) | Hard | forensic

## Информация

> Нам поступила информация, что некая организация Y смогла взломать суперкомпьютер лаборатории Х и наладить канал связи для кражи секретных данных. Учёные лаборатории уже нашли вирус, теперь осталось найти этот канал и узнать какие данные были украдены

## Деплой

`Не требуются`

## Выдать участникам

[`traffic_dump.zip`](public/traffic_dump.zip) из директории [public/](public/)

## Описание

Дамп трафика с внедрёнными пакетами спрятанного канала связи

## Решение

1. Открываем файл `traffic_dump.pcap` через wireshark
2. Ищем любое упоминание флага ("flag").
3. Можно найти диалог начинающийся с пакета в data которого есть строчка `flag start` ![img1.png](src/img1.png)
4. Так же можно заметить что диалог кончается строчкой `flag end` ![img2.png](src/img2.png)
5. Делаем вывод, что мы нашли наш канал связи, осталось лишь расшифровать его. Из диалога можно заметить что некоторые пакеты пустые, а остальные заполнены мусором. Особенно это хорошо видно через длину пакетов 
![img3.png](src/img3.png)
6. Делаем вывод, что это либо двоичный кол, либо азбука морзе (это двоичный)
7. Пишем скриптик который пройдётся по пакетам и преобразует их в 0 и 1
8. После запуска получаем искомый флаг `kevactf{C4tch_me_1f_y0u_can_but_harder}`
