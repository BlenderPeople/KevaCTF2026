# Abacus | Easy | ppc

## Информация

> Вы нашли древние счёты, на которых нужно быстро посчитать сумму результатов множества арифметических выражений — вручную за несколько секунд посчитать ответ невозможно, нужно использовать древнюю технологию решения задач — кодинг. Если ответ верный — ты получишь то, за чем пришёл.
>
> nc <ip> 62223
>
> Ответ к задаче — сумма всех результатов.

## Деплой

Команда для запуска на сервере:

```sh
cd deploy
docker compose up --build -d
```

## Выдать участникам

IP:PORT сервера

## Описание

Участнику предоставляется TCP-сервис, который присылает поток простых арифметических выражений и просит посчитать сумму их результатов, уложившись в таймаут. Нужно написать скрипт, который разберёт поток и вернёт правильный ответ.

## Решение

1. Подключиться к сервису и построчно читать данные до строки `=== Stream ended ===`.
2. Каждая строка имеет вид `op1 знак op2` — разобрать операнды и знак, вычислить результат по тому же знаку операции (`+`, `-`, `*`, `//`, `**`).
3. Просуммировать результаты всех строк.
4. Отправить сумму одной строкой в ответ на приглашение `Answer: ` до истечения таймаута.
