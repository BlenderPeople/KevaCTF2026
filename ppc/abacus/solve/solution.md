# Решение задачи Abacus

## Общая информация

- **Уровень:** Easy
- **Категория:** ppc
- **Навык:** разбор текстового потока и вычисление выражений под таймаутом

---

## Этап 1: Подключение и получение задания

Подключаемся к сервису:

```sh
nc <ip> 62223
```

Сервис сразу присылает список выражений, например:

```
47 + 132
90 // 7
150 - 200
19 ** 3
12 * 88
...

=== Stream ended ===
Answer: 
```

---

## Этап 2: Разбор и вычисление

Читаем строки до маркера `=== Stream ended ===`. Каждая строка — `op1 знак op2`, где знак один из `+ - * // **`. Вычисляем результат каждой строки по её знаку (для `//` — целочисленное деление, как в Python) и суммируем результаты всех строк, включая отрицательные.

---

## Этап 3: Отправка ответа

Отправляем посчитанную сумму одной строкой и получаем флаг:

```sh
python3 solve.py
```

Референсная реализация — в [solve.py](solve.py).
