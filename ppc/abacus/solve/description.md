# Abacus

## Описание

Участнику предоставляется TCP-сервис на asyncio (порт `62223`). При подключении сервис сразу присылает поток простых арифметических выражений и ждёт от клиента один ответ — сумму результатов всех выражений.

## Формат сообщения сервера

```
<число1> <знак1> <число2>
<число1> <знак1> <число2>
...

=== Stream ended ===
Answer: 
```

Строк с выражениями от 30 до 100. Каждая строка независима, разделителей внутри строки кроме пробелов нет.

## Операции

| Знак | Операция                  |
|------|----------------------------|
| `+`  | Сложение                   |
| `-`  | Вычитание                  |
| `*`  | Умножение                  |
| `//` | Целочисленное деление      |
| `**` | Возведение в степень       |

Операнды — целые числа. Для `**` они специально ограничены небольшим диапазоном, чтобы результат не превращался в число из сотен цифр.

## Правило подсчёта

Нужно вычислить результат каждого выражения по указанному знаку и просуммировать результаты всех строк потока (включая отрицательные результаты вычитания). Итоговая сумма — единственное число, которое нужно отправить в ответ.

## Ограничение по времени

На отправку ответа даётся 6 секунд с момента получения задания — вручную посчитать десятки выражений не успеть, нужен скрипт.

## Валидация ответа

Сервис принимает ответ только как обычную (не более 32 символов) целочисленную строку — более длинный или нечисловой ввод отклоняется с понятным сообщением, а не обрывом соединения.
