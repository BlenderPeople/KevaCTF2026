# Решение задачи Uplink

## Общая информация

- **Уровень:** Hard
- **Категория:** ppc
- **Навык:** разбор бинарного протокола (TLV) под таймаутом

---

## Этап 1: Подключение и получение задания

Подключаемся к сервису:

```sh
nc <ip> 64444
```

Сервис сразу присылает список селекторных байт и раунды с данными, например:

```
Селекторные байты (HEX):
0A 1F 42

Последовательность:
SUM
01 03 0A 0B 0C 02 02 FF 01

MAX
...
```

---

## Этап 2: Разбор TLV-потока

Каждый раунд начинается со строки-режима (`SUM`/`MAX`/`SEL`), за ней следует одна строка HEX-байт. Разбираем её как последовательность записей `тип (1 байт) | длина (1 байт) | данные (length байт)` подряд, пока не кончится строка.

Пример из первого раунда выше (режим `SUM`):

- `01 03 | 0A 0B 0C` — тип `0x01`, длина 3, данные `0A 0B 0C`
- `02 02 | FF 01` — тип `0x02`, длина 2, данные `FF 01`

---

## Этап 3: Подсчёт контрольного индекса

Для каждой записи, в зависимости от режима её раунда, накапливаем:

- `SUM` → прибавляем сумму байт данных к общей сумме
- `MAX` → обновляем максимум длины данных, если он больше текущего
- `SEL` → если тип записи есть в списке селекторных байт, увеличиваем счётчик

Все три накопителя общие для всего соединения — они не сбрасываются между раундами. Ответ — `SUM + MAX + SEL`.

Референсная реализация разбора — в [solve.py](solve.py).

---

## Этап 4: Отправка ответа

Отправляем посчитанное число одной строкой и получаем флаг:

```sh
python3 solve.py
```
