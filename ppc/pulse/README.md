# Pulse | Medium | ppc

## Информация

> Вы поймали старый маяк, который мигает почти без остановки — но большая часть вспышек это просто помехи. Внутри него стоит компьютер, который ещё давно потерял связь с ним. Твоя задача — восстановить соединение, решив простую задачу.
>
> nc <ip> 55555
>
> Задача:
>
> **Формат.** Сервис присылает одну длинную строку из символов `0` и `1`, за которой идёт строка `=== Stream ended ===` и приглашение `Max length: `.
>
> **Сигнал.** Внутри потока повторяются короткие «циклы» одного и того же вида: 3-5 единиц, затем ещё одна единица, затем 4-10 нулей, затем снова единица, затем 3-12 нулей. Циклы идут в потоке партиями — несколько циклов подряд без разрывов, — а между партиями вставлен шум: случайные последовательности единиц и нулей, которые не образуют цикл целиком.
>
> **Что нужно сделать.** Найти в потоке самую длинную партию — то есть максимальное количество циклов, идущих непосредственно друг за другом без шума между ними, — и отправить это количество одним числом.

## Выдать участникам

IP:PORT сервера

## Описание

Участнику предоставляется TCP-сервис, который присылает длинный поток из `0` и `1`, содержащий повторяющийся сигнальный паттерн вперемешку с шумом. Нужно написать скрипт, который найдёт самую длинную непрерывную серию сигнала и вернёт её длину, уложившись в таймаут.

## Решение

1. Подключиться к сервису и читать поток до строки `=== Stream ended ===`.
2. Найти в потоке все вхождения цикла (регулярное выражение `1{3,5}10{4,10}10{3,12}`).
3. Найти самую длинную последовательность вхождений, идущих строго подряд (конец одного совпадения равен началу следующего).
4. Отправить длину этой последовательности (количество циклов в ней) одним числом в ответ на приглашение `Max length: `.
