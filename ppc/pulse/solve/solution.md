# Решение задачи Pulse

## Общая информация

- **Уровень:** Medium
- **Категория:** ppc
- **Навык:** регулярные выражения, поиск сигнала в шуме под таймаутом

---

## Этап 1: Подключение и получение потока

Подключаемся к сервису:

```sh
nc <ip> 55555
```

Сервис сразу присылает длинный поток из `0` и `1`, например (сильно сокращённо):

```
111100000001000...1111100000000000001000...0011111000001000
=== Stream ended ===
Max length: 
```

---

## Этап 2: Поиск циклов

Цикл описывается регулярным выражением:

```
1{3,5}10{4,10}10{3,12}
```

Ищем все вхождения этого паттерна в потоке (до маркера `=== Stream ended ===`) через `re.finditer`.

---

## Этап 3: Поиск самой длинной партии

Партия — это несколько найденных вхождений, идущих строго подряд: конец одного совпадения (`match.end()`) равен началу следующего (`match.start()`). Проходим по всем найденным совпадениям и считаем длину каждой такой непрерывной цепочки, запоминая максимум.

---

## Этап 4: Отправка ответа

Отправляем найденный максимум одной строкой в ответ на приглашение `Max length: ` и получаем флаг:

```sh
python3 solve.py
```

Референсная реализация — в [solve.py](solve.py).
