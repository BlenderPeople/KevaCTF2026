# Meridian Air

## Описание

Участнику предоставляется веб-приложение личного кабинета авиакомпании Meridian Air. Пользователи могут регистрироваться, авторизовываться и просматривать страницу уведомлений. В ходе решения задачи необходимо обнаружить и проэксплуатировать уязвимость в форме входа, чтобы получить доступ под учётной записью администратора.

## Техническая информация

Приложение построено на фреймворке FastAPI, для хранения пользователей используется PostgreSQL.

### Уязвимый функционал

Форма входа (`POST /login`) принимает логин и пароль и напрямую подставляет введённый логин в SQL-запрос без параметризации:

```python
query = text(
    f"SELECT * FROM \"User\" WHERE login = '{login}' AND hash_password = '{hash_password}'"
)
```

В отличие от формы регистрации, эндпоинт `/login` не проверяет логин на длину и допустимые символы — там используется другой механизм приёма формы, без этих ограничений. Клиентская проверка на странице входа (запрет пробелов) не мешает эксплуатации, так как рабочий payload пробелов не содержит.

### Учётная запись администратора

При первом запуске приложение автоматически создаёт пользователя `admin` со случайным сгенерированным паролем — угадать или подобрать его невозможно. Попасть в аккаунт можно только через уязвимость в форме входа.

## Структура приложения

```
/
├── Главная страница /agency
├── Уведомления /alerts
├── Настройки /settings
├── Поддержка /support
├── Вход /login
└── Регистрация /register
```
