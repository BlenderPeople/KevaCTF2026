# Решение задачи Meridian Air

## Общая информация

- **Уровень:** Easy
- **Категория:** web
- **Уязвимость:** SQL-инъекция (SQLi)
- **Вектор атаки:** SQLi в форме входа → обход проверки пароля → авторизация под `admin`

---

## Этап 1: Поиск уязвимости

Переходим на страницу **«Вход»** (`/login`). Пробуем ввести в поле логина одинарную кавычку:

```
'
```

Сервер отвечает ошибкой — это подтверждает, что введённое значение попадает в SQL-запрос без экранирования.

---

## Этап 2: Обход проверки пароля

Запрос на бэкенде выглядит так:

```python
SELECT * FROM "User" WHERE login = '{login}' AND hash_password = '{hash_password}'
```

Если подставить в поле логина:

```
admin'--
```

запрос превращается в:

```sql
SELECT * FROM "User" WHERE login = 'admin'--' AND hash_password = '...'
```

`--` комментирует всё, что идёт после — включая проверку пароля. В результате запрос ищет пользователя только по логину `admin`, и пароль в форме может быть любым.

---

## Этап 3: Авторизация

Вводим на странице `/login`:

- **Логин:** `admin'--`
- **Пароль:** любой, например `1234`

Сервер находит пользователя `admin` и авторизует под ним, не проверив пароль.

---

## Этап 4: Получение флага

После входа переходим на любую страницу личного кабинета, например `/agency`. В боковом меню в блоке профиля отображается статус аккаунта — для `admin` это флаг.
