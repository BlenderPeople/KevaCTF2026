# Labyrinth — пошаговое решение

## Шаг 1. Подготовка webhook.site

Откройте [webhook.site](https://webhook.site/) — сервис автоматически сгенерирует
уникальный URL и покажет все входящие запросы. Скопируйте этот URL, он
понадобится для перехвата SSRF-запроса.

## Шаг 2. SSRF — перехват user_id администратора

На странице `/message` доступна форма «Отправить токен другому пользователю».
Эндпоинт `POST /send-token` берёт логин целевого пользователя, находит его
в базе данных и делает POST-запрос на указанный URL, отправляя в теле запроса
`user_id` из БД и `token` — значение, которое мы сами указали в форме.

Заполните параметры запроса:
- **Login:** `admin`
- **URL:** ваш URL с webhook.site (из шага 1)
- **Token:** любая строка ровно из 64 символов (содержимое не проверяется,
  только длина)

Отправьте запрос. На webhook.site придёт POST-запрос с JSON-телом, в котором
будет поле `user_id` со значением `354969` — это идентификатор администратора
из базы данных. Именно его мы и добываем через SSRF.

## Шаг 3. Брут секрета JWT

```
hashcat -a 0 -m 16500 <ваш-jwt-токен> rockyou.txt
```

## Шаг 4. Подделка JWT-токена

Создайте JWT с payload:
- `sub`: `354969`
- `username`: `admin`
- `status`: `Admin`
- `iat`: текущее время
- `exp`: текущее время + 30 минут

Подпишите токен алгоритмом `HS256` с ключом `trustno1`.

## Шаг 5. Установка forged JWT в cookie

Установите поддельный JWT в cookie `access_token` вашего браузера. Теперь вы
аутентифицированы как администратор — сервер не проверяет существование
пользователя в БД при `sub=354969`.

## Шаг 6. Получение token администратора через /profile

Перейдите на страницу `/profile` и достаньте токен в поле "Токен доступа".

## Шаг 7. Чтение флага

Перейдите на страницу `/files`. Нажмите на файл **TopSecretFile** — откроется модальное окно для ввода токена. Вставьте token администратора, полученный со страницы `/profile`.

Сервер проверит, что token принадлежит пользователю с `user_id == 354969` и вернёт содержимое файла — флаг.
