# Labyrinth — описание решения

## Описание приложения

Веб-приложение стилизовано под терминал заброшенного комплекса. Пользователи
могут регистрироваться, просматривать профиль со своим access token,
редактировать логин и пароль, «отправлять» токены другим пользователям
через SSRF-уязвимый эндпоинт `/send-token`, а также просматривать библиотеку
файлов, среди которых `TopSecretFile` — доступен только с access token
администратора из БД.

## Решение

Через SSRF на `/send-token` получаем `user_id` администратора → брутим
секрет JWT через hashcat → подделываем JWT с `sub=user_id` админа →
заходим на `/profile` и копируем его access token из БД → открываем
`TopSecretFile` с этим токеном → флаг.
