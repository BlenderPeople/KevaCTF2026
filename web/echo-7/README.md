## Описание

Веб-приложение научного центра «Эхо-7»: регистрация, карточки исследователей, оповещения, настройки и поддержка. Нужно найти и проэксплуатировать уязвимость, чтобы получить доступ к скрытой admin-панели.

## Решение

1. Поле «Организация» в форме добавления исследователя уязвимо к SSTI. Payload `{{7*7}}` подтверждает уязвимость.

2. Через dirb находится страница `/debug` с информацией об ошибке фильтра `_ae`. Из сообщения становится понятно, что фильтр требует `secret_token`.

3. На странице «Поддержка» в HTML-коде (JavaScript-комментарий) находится `secret_token`.

4. Используя SSTI, вызывается фильтр `_ae` с найденным токеном и параметром `env_name=.env.admin`. В ответе возвращаются переменные окружения, включая `JWT_KEY` и `ADMIN_URL`.
payload: `{{''|_ae('ad563982011c2685d697a1aeb1e9552ec401cc47500853d3db876a8d71317350', '.env.admin')}}` 

5. С помощью украденного `JWT_KEY` создаётся поддельный токен со статусом `Admin`.

6. В `.env.admin` лежит ссылка на скрытую admin-панель. Заменив JWT токен в cookie "access_token", пользователь переходит на страницу "/relay/h4v3n/EchoOverr1de/adminGate9k3z" и находит флаг.
