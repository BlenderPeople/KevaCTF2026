# Лаборатория X: Научный центр «Эхо-7»

## Описание

Участнику предоставляется веб-приложение Научного центра «Эхо-7». Пользователи могут регистрироваться, авторизовываться, создавать карточки исследователей, просматривать архив, работать с разделами оповещений и поддержки, а также изменять параметры профиля. В ходе решения задачи необходимо обнаружить и проэксплуатировать уязвимость в приложении для получения доступа к скрытой admin-панели.

## Техническая информация

Приложение построено на фреймворке FastAPI с использованием шаблонизатора Jinja2.

### Уязвимый функционал

Форма добавления нового исследователя содержит поле «Организация», которое обрабатывается через Jinja2. В приложении реализована песочница для защиты от SSTI-атак, однако она допускает выполнение ограниченного набора выражений.

### Ограничения песочницы

Jinja2-песочница блокирует большинство опасных конструкций:
- Доступ к `__class__`, `__mro__`, `__subclasses__`, `__globals__`, `__builtins__`
- Вызов `lipsum()`, `cycler`, `joiner`, `namespace`
- Доступ к `request`, `session`, `config`, `g`
- Функции `open()`, `eval()`, `exec()`, `compile()`
- И другие опасные атрибуты и методы

**Разрешены:**
- Простые арифметические выражения: `{{7*7}}`, `{{100+50}}`, `{{2**3}}`
- Базовые операции со строками
- Вызов кастомного фильтра `_ae()` с определёнными параметрами

### Кастомный фильтр `_ae`

В приложении зарегистрирован кастомный фильтр `_ae` для чтения переменных окружения из файла `.env.admin`. Фильтр требует два параметра:
1. `secret_token` — секретный токен для авторизации запроса
2. `env_name` — имя файла окружения (например, `.env.admin`)

Пример вызова:
```jinja2
{{''|_ae('secret_token_value', '.env.admin')}}
```

Без корректного `secret_token` фильтр возвращает ошибку.
