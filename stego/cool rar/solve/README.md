## Решение
Получаем png изображение. Можно попробовать проверить rgb, слои и прочее, но там пусто. Провери на наличие скрытых файлов, найдём архив. Архив под паролём, нужно использовать брутфорс, выбрав самый популярный словарь rockyou мы подберём нужный пароль. Там лежит .exe файл с игрой, всего там 8 уровней на каждом из которых необходимо расшифровать сообщение и написать его в ответ, после прохождения всех уровней - будет флаг.
