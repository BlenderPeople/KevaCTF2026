# Carpet | Easy | stego

## Информация

> Двери супер секретной лаборатории открываются перед вами... стоп, почему они закрыты? И кто додумался поменять пароль в день открытия?! Может здесь есть ключ под ковриком?


## Деплой

`Не требуются`

## Выдать участникам

[`Suspicious carpet.png`](public/Suspicious%20carpet.png) из директории [public/](public/)

## Описание

"Велком" таска состоящая из картинки "ковра"

## Решение
Решение получается весьма тривиальным, хотя "велком" таска на то и "велком"
1. Открываем файл `Suspicious carpet.png`, видим ковёр
2. Замечаем его ассиметричность.
3. Замечаем что точки по кромке ковра имеют определённый патерн
4. Выписываем их принимая за 0 и 1
5. Получаем строчку `011100010111011101100101011100100111010001111001001100010011001000110011`
6. Запихиваем в ascii декодер
7. Получаем ответ `qwerty123`
8. По условию задачи знаем что нам нужен ключ от кодовой двери, поздравляю мы его и нашли
По итогу имеем флаг `kevactf{qwerty123}`
