## Решение
[Решение](solve/solve.py)
1)Открываем файл "encrypt_pt1.py", сразу видно, что алгоритм XORит изображение по 16-байтному ключу, который генирируется в моменте.
2)Мы видим, что изначальный файл имеет разрешение .png, а это значит, что первые 16 байт этого файла являются статичным png заголовком. Зная это, xorим первые 16 байт "key_leak.txt" c 16 байтами png заголовка и получаем ключ.
3)С помощью ключа XORим весь файл key_leak.txt. Получаем исходный png, там мы имеем все параметры для AES
4)Последние 2 байта iv неизвестны, будем перебирать. Пишем скрипт для AES, где в iv подаём цикл из возможных вариантов байтовых комбинаций.
5)Итоговый флаг находится в диапазоне bbbb-dddd hex-значений байтов, что можно заметить визуально, выводя результаты дешифровки в консоль, собственно, при bccb мы и получаем искомый флаг
