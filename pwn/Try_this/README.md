## Решение

Наша задача выбрать в меню войти, в этом случае вызывается уязвимая функция, в которой есть переманная buffer и flag, переменная flag находится после переменной buffer, у пользователя есть возможность ввести больше символов, чем может в себя поместить буфер. При переполнении buffer перезаписывается переменная flag и тем самым проверка пароля проходится успешно и происходит обращение к функции win, которая читает из переменной окружения FLAG сам флаг.
