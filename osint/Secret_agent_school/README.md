## Описание

## Решение
1. По ФИО можно найти Школу (очень просто)
2. Если искать "ФИО ТУСУР", то можно найти страницу ГПО, где уже будет находится номер группы
3. Номер группы в ТУСУРе скрывает в себе год поступления
4. Год поступления в ВУЗ = год выпуска из школы
